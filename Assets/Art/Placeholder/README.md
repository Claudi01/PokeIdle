# Sprites placeholder

Coloque aqui os PNGs temporarios das criaturas.

No Unity:

1. Selecione o PNG no Project window.
2. No Inspector, use `Texture Type: Sprite (2D and UI)` e `Sprite Mode: Single`.
3. Para pixel art, use `Filter Mode: Point` e clique em `Apply`.
4. Selecione os assets em `Assets/Resources/PokeIdle/Demo/Creatures`.
5. Atribua os sprites dianteiro/traseiro de Charmander, Caterpie, Squirtle, Metapod, Weedle, Pidgey e Rattata.

Os sprites ficam na subpasta `Pokemon`. Use o menu `PokeIdle > Assign Placeholder Sprites` para configurar os importadores e preencher os assets automaticamente.

Metapod, Weedle, Pidgey e Rattata possuem definicoes de dados e sprites de frente/trás no prototipo. O menu tambem os atribui automaticamente aos respectivos assets de criatura.

Os sprites sao apenas placeholders de prototipagem. Antes de distribuir o jogo, substitua-os por arte original licenciada.
