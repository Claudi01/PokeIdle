# Sprites placeholder

Coloque aqui os PNGs temporários das criaturas.

No Unity:

1. Selecione o PNG no Project window.
2. No Inspector, use `Texture Type: Sprite (2D and UI)` e `Sprite Mode: Single`.
3. Para pixel art, use `Filter Mode: Point` e clique em `Apply`.
4. Selecione os assets em `Assets/Resources/PokeIdle/Demo/Creatures`.
5. Atribua os sprites dianteiro/traseiro de Charmander, Caterpie e Squirtle.

Se os PNGs estiverem na subpasta `Pokemon`, use o menu `PokeIdle > Assign Placeholder Sprites` para configurar os importadores e preencher os assets automaticamente.

Os sprites são apenas placeholders de prototipagem. Antes de distribuir o jogo, substitua-os por arte original licenciada.
